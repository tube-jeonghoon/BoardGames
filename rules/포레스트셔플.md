# 🎲 포레스트 셔플 (Forest Shuffle)

## 🧩 한줄 요약

나무를 심고 그 주위에 동식물을 배치해 생태계를 완성하는 카드 핸드 관리 게임. 세 번째 겨울 카드가 나오면 즉시 종료

---

## 👥 플레이어 정보

| 항목 | 내용 |
|------|------|
| 최소 인원 | 2명 |
| 최대 인원 | 5명 |
| 추천 인원 | 3~4명 |
| 플레이 시간 | 약 40~60분 |
| 난이도 | BGG 기준 약 2.0 / 5 |

---

## ⚙️ 메커니즘

- 오픈 드래프팅 (Open Drafting)
- 핸드 관리 (Hand Management)
- 타블로 빌딩 (Tableau Building)
- 세트 수집 (Set Collection)
- 멀티 유즈 카드 (Multi-Use Cards)
- 체이닝 (Chaining)
- 종료 보너스 (End Game Bonuses)

---

## 🌍 세계관 / 테마

울창한 숲 속, 플레이어들은 각자의 숲을 가꾸는 생태학자다.  
나무를 심고 그 나무에 동물·식물·곤충을 유치해 **가장 풍요로운 생태계**를 만드는 것이 목표.  
하지만 겨울이 세 번 오면 게임이 즉시 끝나기 때문에, 빠르고 효율적인 카드 플레이가 관건이다.

---

## 🏆 승리 조건

게임 종료 시 **내 숲의 모든 카드 점수 합산이 가장 높은 플레이어** 승리.

점수 출처:
- 🌳 **나무 카드** — 카드에 표시된 고유 점수 조건
- 🦊 **동식물(분할 카드)** — 나무에 붙인 카드의 도토리 아이콘 점수
- 🦔 **동굴 카드에 숨긴 카드** — 숨긴 카드 1장당 1점
- 동점 시: 공동 우승

---

## 🔁 전체 게임 흐름

```
[준비]
 플레이어 수에 따라 카드 일부 제거 후
 덱에 겨울 카드 3장을 섞어 넣음
 각자 손패 6장 + 동굴 카드 1장
        ↓
[자기 턴 — 둘 중 하나 선택]
 A. 카드 2장 드로우 (광장 또는 덱에서)
 B. 카드 1장 플레이 → 광장 확인
        ↓
 ... 반복 ...
        ↓
[종료 트리거]
 덱에서 세 번째 겨울 카드를 뽑는 순간 즉시 종료
        ↓
[점수 계산]
 각자 숲의 모든 카드 점수 합산 + 동굴 카드 점수
```

---

## 🎮 턴 구조

매 턴 아래 두 행동 중 **하나만** 선택한다.

---

### 🅐 카드 2장 드로우

광장(공개 버림더미)이나 덱에서 원하는 순서로 1장씩 총 2장을 가져와 손패에 추가.

- 광장 카드: 앞면 공개 상태 → 원하는 카드 선택 가능
- 덱 카드: 뒷면 → 무작위 드로우
- **손패 최대 10장 제한** (9장 이상이면 이 행동 불가)

---

### 🅑 카드 1장 플레이 + 광장 확인

**① 카드 비용 지불**
손패에서 카드 1장을 플레이하되, 좌측 상단의 비용만큼 손패 카드를 **광장에 버린다**.

> 예: 비용 3 → 손패에서 카드 3장을 광장에 내려놓음

**② 잎사귀 보너스 확인 (선택적 추가 행동)**
비용으로 버린 카드들이 **카드에 표시된 잎 색상과 일치**하면 보너스 행동 즉시 발동.
- 보너스는 카드마다 다름 (예: 카드 드로우, 추가 카드 플레이 등)

**③ 카드를 숲에 배치**
- 나무 카드 → 내 앞에 세로로 세워 배치 (나무를 심음). 배치 시 덱 상단 카드 1장을 광장에 공개
- 분할 카드(동식물) → 이미 심은 나무 위/아래/왼쪽/오른쪽 슬롯에 꽂아 넣음

**④ 광장 확인**
광장에 카드가 **10장 이상** 쌓이면 → 광장의 모든 카드를 버림 더미로 제거 (덱에 돌아가지 않음)

---

## 🧱 카드 종류 상세

### 🌳 나무 카드

숲의 기반이 되는 카드. 총 **4개의 슬롯** (위·아래·왼쪽·오른쪽)을 가짐.

- 플레이 시 덱 상단 1장을 광장에 공개
- 나무가 없을 경우, 손패 카드를 **묘목(사플링)** 으로 뒤집어 배치 가능 (나무처럼 슬롯 4개 생기지만 고유 효과 없음)
- 종료 시 나무 카드 자체의 점수 조건 계산

**주요 나무 종류:** 참나무, 너도밤나무, 자작나무, 전나무, 소나무, 단풍나무 등

---

### 🦊 분할 카드 (동물·식물·곤충)

하나의 카드에 **두 종류의 생물**이 위아래 또는 좌우로 나뉘어 그려진 카드.

- 나무 슬롯에 꽂으면 **한쪽 면만 보임** → 보이는 면의 효과와 점수만 적용
- 꽂히는 방향에 따라 다른 생물이 활성화됨
- 나무의 위/아래 슬롯 → 세로 분할 카드 사용
- 나무의 왼쪽/오른쪽 슬롯 → 가로 분할 카드 사용

**대표 카드 예시:**

| 카드 | 슬롯 | 점수 조건 예시 |
|------|------|---------------|
| 올빼미 / 딱따구리 | 위·아래 | 내 숲의 나무 수 × 점수 |
| 토끼 / 고슴도치 | 위·아래 | 내 숲의 같은 종류 동물 수 × 점수 |
| 버섯 / 이끼 | 위·아래 | 인접 나무 종류에 따라 점수 |
| 두더지 / 개미 | 왼·오른쪽 | 특정 조건 충족 시 고정 점수 |
| 곰 / 너구리 | 왼·오른쪽 | 동굴에 카드 숨기기 허용 |

---

### ❄️ 겨울 카드 (Winter Card)

덱 안에 3장 섞여 있는 **종료 트리거 카드**.

- 드로우 행동 중 또는 나무 카드 플레이 시 공개되어 겨울 카드가 나오면 광장에 놓임
- **세 번째 겨울 카드가 드로우되는 즉시 게임 종료** (진행 중인 턴도 완료하지 않음)

---

### 🏚 동굴 카드 (Cave Card)

각 플레이어가 1장씩 갖는 개인 카드. 점수 없음.

- 곰·너구리 같은 특정 동물 카드의 효과로 손패 카드를 동굴 아래에 숨길 수 있음
- 게임 종료 시 동굴 아래 숨긴 카드 **1장당 1점**

---

## ⚠️ 자주 헷갈리는 규칙 / 예외 상황

- **세 번째 겨울 카드는 즉시 종료**: 뽑은 플레이어가 자기 턴을 끝마치지 못함. 진행 중인 행동도 중단
- **광장 제거는 턴 끝 시점**: 광장이 10장 이상이 되어도 즉시 치우지 않고, 카드 플레이 행동이 모두 끝난 뒤에 제거
- **묘목(사플링)**: 나무 카드가 없을 때 다른 카드를 뒤집어 묘목으로 쓸 수 있으나 그 카드 고유의 점수·효과는 사라짐
- **분할 카드는 한 면만**: 꽂은 방향의 생물만 활성화. 뒤에 숨겨진 면의 점수·효과는 없음
- **손패 10장 제한**: 드로우 행동 시 9장 이상이면 드로우 불가 → 카드를 플레이해야 함
- **잎사귀 보너스**: 비용으로 낸 카드 전부가 지정 색상이어야 발동. 일부만 맞으면 보너스 없음
- **나무 없이 시작**: 손패에 나무 카드가 없으면 첫 턴 전 무조건 패를 다시 받을 수 있음 (1회 한정 멀리건)

---

## 💡 초보자 팁

- **나무 먼저 심어라** — 나무 없이는 동식물 카드를 배치할 슬롯이 없음. 초반에 나무 2~3그루를 확보하는 게 우선
- **잎사귀 보너스를 노려라** — 비용 카드의 색을 맞추면 추가 행동이 발생해 효율이 크게 오름. 같은 색 카드를 모아두는 것이 좋음
- **광장을 전략적으로 활용** — 광장은 앞면이 보여 다음 드로우 시 원하는 카드를 가져올 수 있음. 내가 쓰고 싶은 카드를 비용으로 내려 광장에 깔아두고 다음 턴에 드로우하는 전략도 유효
- **겨울 카드를 의식하자** — 이미 2장이 나왔다면 게임이 곧 끝남. 손패를 서둘러 플레이하고 점수를 확정지어야 함
- **토끼·고슴도치 같은 승수 카드 주의** — 단독으론 약하지만 같은 종류가 많이 모이면 폭발적인 점수를 냄. 상대가 특정 종류를 집중적으로 모으고 있다면 경계할 것
- **참고 카드(레퍼런스 카드)를 활용** — 14장의 참고 카드에 모든 카드의 점수 조건이 설명되어 있음. 첫 몇 판은 적극적으로 펼쳐보자
