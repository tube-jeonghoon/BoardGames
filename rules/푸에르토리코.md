# 🎲 푸에르토리코 (Puerto Rico)

## 🧩 한줄 요약

역할 선택으로 플랜테이션을 개발하고, 상품을 생산·판매·선적해 승점을 가장 많이 모으는 전략 보드게임

|------|------|

| 난이도 | BGG 기준 3.25 / 5 |

- 자원 관리 (Resource Management)
- 루트 빌딩 / 엔진 빌딩 (Engine Building)

## 🌍 세계관 / 테마

17세기 카리브해의 섬 푸에르토리코를 배경으로 한다.  
플레이어들은 각자 섬의 **총독**이 되어 플랜테이션을 일구고, 상품을 생산해 유럽으로 수출하며 섬을 발전시킨다.  
누가 가장 번영한 식민지를 건설하느냐를 겨루는 게임이다.

---

## 🏆 승리 조건

게임 종료 시 **승점(VP)이 가장 많은 플레이어**가 승리한다.

승점 획득처:
- 📦 **선적** — 화물선에 상품을 실으면 실은 개수만큼 VP 획득
- 🏛 **건물** — 건물 타일 자체에 VP가 표시됨 (대형 건물일수록 높음)

**게임 종료 조건 (즉시 종료, 라운드 끝에 확인):**
1. VP 칩이 모두 소진됨
2. 한 플레이어의 섬 건물 공간(12칸)이 모두 채워짐
3. 식민지 공급 칸의 식민지(콜로니스트)가 바닥남

## 🔁 전체 게임 흐름

```
[라운드 시작]
 총독이 역할 카드 1장 선택 → 행동 수행
     ↓
 다음 플레이어가 역할 카드 1장 선택 → 행동 수행
     ↓
 ... (모든 플레이어가 역할 1장씩 선택)
     ↓
 남은 역할 카드에 더블룬 1개 추가 (다음 라운드 매력도 증가)
     ↓
 총독 토큰을 왼쪽으로 전달 → 다음 라운드
```

핵심 흐름 요약:  
**플랜테이션 개발 → 식민지 배치 → 건물 건설 → 상품 생산 → 판매/선적 → VP 축적**

## 🎮 턴 구조

### 총독(Governor) 시스템

- 매 라운드, **총독 토큰을 가진 플레이어**가 먼저 역할 카드를 선택
- 한 라운드에서 각 플레이어는 **역할 카드 1장씩** 선택
- 선택된 역할의 행동은 **모든 플레이어가 순서대로 수행**
- 단, **역할을 선택한 플레이어만** 해당 역할의 **특권(Privilege)** 획득

### 역할 카드 종류 (2~5인용)

| 역할 | 특권 |
|------|------|
| 정착자 (Settler) | 채석장 타일 추가 선택 가능 |
| 시장 (Mayor) | 식민지 1개 추가 획득 |
| 건축가 (Builder) | 건물 비용 1더블룬 할인 |
| 장인 (Craftsman) | 상품 1개 추가 생산 |
| 상인 (Trader) | 판매 시 더블룬 1개 추가 |
| 선장 (Captain) | 선적 시 VP 1개 추가 |
| 투기꾼 (Prospector) | 더블룬 1개 획득 (4~5인 전용) |

## 🧱 페이즈별 설명

### 1️⃣ 정착자 (Settler)

**무엇을 하는가:** 플랜테이션 타일을 가져와 섬에 배치

- 공개된 플랜테이션 타일 중 1장 선택 → 내 섬 빈 공간에 배치
- **특권:** 일반 플랜테이션 대신 **채석장(Quarry)** 타일 선택 가능
- 남은 타일 버리고 새 타일 공개

**플랜테이션 종류:** 옥수수, 인디고, 설탕, 담배, 커피

**제한:** 섬 공간은 총 12개 (건물 공간과 공유하지 않음)

---

### 2️⃣ 시장 (Mayor)

**무엇을 하는가:** 식민지를 받아 플랜테이션·건물에 배치

- 화물선(식민지 배)에서 식민지를 순서대로 1개씩 가져옴
- **특권:** 1개 추가 획득
- 받은 식민지를 내 플랜테이션·건물의 빈 칸에 자유롭게 배치

**핵심 원칙:**
- 플랜테이션에 식민지 배치 → 해당 플랜테이션 **활성화** (생산 가능)
- 건물에 식민지 배치 → 해당 건물 **활성화** (효과 발동)

---

### 3️⃣ 건축가 (Builder)

**무엇을 하는가:** 더블룬을 내고 건물을 구매해 섬에 배치

- 건물 공급 구역에서 원하는 건물 1개 구매
- **특권:** 건물 비용 1더블룬 할인
- 채석장(활성화된 것)이 있으면 추가 할인 (채석장당 1더블룬, 건물 크기에 따라 최대 할인 한도 상이)

**건물 종류:**
| 구분 | 내용 |
|------|------|
| 소형 생산 건물 | 인디고 공장(소), 설탕 공장(소) — 식민지 칸 1개 |
| 대형 생산 건물 | 인디고 공장, 설탕 공장, 담배 저장소, 커피 볶음소 — 식민지 칸 3개 |
| 보라색 건물 | 특수 효과 건물 (아래 참조) |

**주요 보라색 건물:**
- **소형 시장** — 판매 시 +1 더블룬
- **대형 시장** — 판매 시 +2 더블룬
- **항구** — 선적 시 +1 VP
- **공장** — 생산 상품 종류에 따라 더블룬 획득
- **사무소** — 교역소에 같은 상품이 있어도 판매 가능
- **부두** — 나만의 사설 화물선 (모든 상품 선적 가능)
- **길드홀** — 생산 건물 개수에 따라 추가 VP (게임 종료 시)
- **요새** — 내 식민지 수에 따라 추가 VP
- **관세청** — 내 VP 칩 수에 따라 추가 VP
- **시청** — 보라색 건물 수에 따라 추가 VP

---

### 4️⃣ 장인 (Craftsman)

**무엇을 하는가:** 상품을 생산

**생산 조건:** 활성화된 플랜테이션 + 활성화된 생산 건물 + 두 곳 모두에 식민지

| 상품 | 플랜테이션 | 생산 건물 |
|------|-----------|----------|
| 옥수수 | 옥수수 | **없음** (건물 불필요) |
| 인디고 | 인디고 | 인디고 공장 |
| 설탕 | 설탕 | 설탕 공장 |
| 담배 | 담배 | 담배 저장소 |
| 커피 | 커피 | 커피 볶음소 |

- **특권:** 상품 1개 추가 생산 (종류 자유 선택)

---

### 5️⃣ 상인 (Trader)

**무엇을 하는가:** 상품 1개를 교역소에 팔아 더블룬 획득

**판매 가격:**
| 상품 | 가격 |
|------|------|
| 옥수수 | 0 더블룬 |
| 인디고 | 1 더블룬 |
| 설탕 | 2 더블룬 |
| 담배 | 3 더블룬 |
| 커피 | 4 더블룬 |

- **특권:** +1 더블룬 추가
- 교역소는 4칸. 같은 상품이 이미 있으면 **판매 불가** (사무소 건물 제외)
- 교역소가 꽉 차면 라운드 끝에 비움

---

### 6️⃣ 선장 (Captain)

**무엇을 하는가:** 화물선에 상품을 선적해 VP 획득

- 화물선에는 상품 종류별로 1종류만 선적 가능
- 실을 수 있는 상품이 있으면 **반드시** 선적해야 함
- 실은 개수만큼 VP 칩 획득
- **특권:** +1 VP 추가
- 선적 후 남은 상품은 **창고 용량** 내에서만 보관 (초과분 버림)

---

## ⚠️ 자주 헷갈리는 규칙 / 예외 상황

- **식민지 배치 순서:** 시장 페이즈에서 받은 식민지는 그 자리에서 즉시 배치해야 함. 나중으로 미룰 수 없음
- **채석장 할인 한도:** 소형 건물은 최대 1더블룬 할인, 대형 건물은 최대 2더블룬, 고가 보라색 건물은 최대 3더블룬까지만 할인됨
- **선장 페이즈 강제 선적:** 상품을 실을 수 있는 배가 있으면 반드시 실어야 함. 선택이 아님
- **옥수수 생산:** 옥수수는 건물 없이 플랜테이션에 식민지만 있으면 생산됨 (유일한 예외)
- **화물선의 종류:** 화물선 크기는 플레이어 수에 따라 다르며, 가득 찬 배는 라운드 끝에 비워짐
- **VP 칩 소진 즉시 종료:** VP 칩이 부족하면 있는 만큼만 나눠주고 라운드가 끝나면 게임 종료
- **역할 카드 더블룬 누적:** 선택되지 않은 역할 카드에는 매 라운드 더블룬 1개씩 쌓임. 나중에 그 역할을 선택한 플레이어가 누적된 더블룬을 모두 가져감

## 💡 초보자 팁

- **채석장을 빨리 확보하라** — 채석장은 건물 비용을 줄여줘 장기적으로 엄청난 이득. 초반에 채석장 1~2개 확보를 목표로 하자
- **대형 건물이 게임을 결정한다** — 게임 후반 길드홀, 요새, 관세청 등 대형 보라색 건물이 10VP 이상을 줄 수 있음. 게임 종료 시점을 계산하며 타이밍을 맞춰야 함
- **다른 플레이어가 선택한 역할도 내 행동** — 내가 역할을 선택하지 않아도 모든 역할 행동에 참여할 수 있음. 특권만 없을 뿐
- **상품 다양성을 노려라** — 공장(Factory) 건물이 있다면 옥수수, 인디고, 설탕, 담배, 커피를 골고루 생산할수록 더블룬을 많이 받음
- **선적과 판매의 균형** — 더블룬(현금)은 판매에서, VP는 선적에서 얻음. 둘 다 놓치지 않는 균형 잡힌 전략이 필요
- **총독 순서를 의식하라** — 앞 순서일수록 원하는 역할을 먼저 선택할 수 있음. 뒷순서라면 상대가 선택한 역할에서 이익을 극대화하는 전략이 필요
